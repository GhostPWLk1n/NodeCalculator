# NodeCalculate v1.6.3

Первый релиз после **v1.5.0** — версии 1.6.0/1.6.1/1.6.2 отдельно не
публиковались, поэтому здесь собран весь путь: план 1.6.0 целиком
(новые типы данных, новые ноды, инструменты холста) плюс три патча,
дошедшие до 1.6.3. Формат `.ncp` не менялся — проекты из 1.5.0
открываются без преобразований.

## ✨ Главное

### Тип данных Bool и логика
Новый род сокета — **Bool** (розовый ромб). Две новые ноды:
**«Булево»** — переключатель истина/ложь, и **«Логическая операция»** —
И/ИЛИ/искл.ИЛИ/НЕ над произвольным числом входов. Булевы значения в
таблицах и на Доске теперь показываются чекбоксом, а не текстом
`true`/`false`.

### Диаграмма Ганта: столбец номеров, доработки
Диаграмма получила столбец номеров строк (как в Excel), свободный
ресайз по вертикали и переосмысленный сокет `any`.

### Новые ноды для работы с деревьями/иерархиями
- **«Дерево»** — сводит несколько подключённых «веток» (таблиц или
  списков) в один свод по совпадающим полям, с рекурсивной вложенностью
  прямо через обычные соединения графа.
- **«Оформление дерева»** и **«Просмотр дерева»** — раскрываемая/
  сворачиваемая иерархия, включая ветки-списки и «листья» без
  дальнейшей вложенности.
- **«Импорт JSON»** — загружает произвольный `.json` и сразу разворачивает
  его в ту же структуру, что понимает «Просмотр дерева», включая файлы
  с «двойным кодированием» (JSON внутри JSON-строки).

### Работа со списками и таблицами
- **«Преобразование списка»** — превращает столбец таблицы (или пару
  столбцов) в редактируемый список, с принудительным форматом значений
  (Число/Текст/Логическое) и защитой ручных правок от затирания при
  повторном пересчёте.
- **«Найти уникальные»** — группировка по ключевому столбцу с гибкой
  агрегацией по остальным (сумма/мин/макс/среднее/первое значение/
  перечислить).
- **«Отсеять»** — условия по столбцам теперь можно задавать подключённым
  списком «имя → истина/ложь», а не только текстом в панели.

### Изображения и организация графа
- **«Изображение»** — источник для локальных файлов, с превью и
  показом на Доске (вписывание по рамке/заполнению/растяжению).
- **«Точка»** — узел-разводка (по образцу Reroute в Blender) для
  аккуратной прокладки длинных соединений в обход других нод.

### Инструменты холста
Новая вертикальная панель инструментов: **обрезание связей** жестом
мыши (по фактической кривой линии, не по приближению), **добавление
точки** кликом, **выделение рамкой** с групповым перемещением. Плюс
поиск нод в сайдбаре по имени и категории, удаление выделенного по
клавише `Delete`, двухцветные линии соединений (цвет источника →
цвет получателя).

### Что сознательно отложено
**Undo/Redo** — кнопки уже в топбаре (пока неактивны), сама реализация
намеренно отложена до более зрелой версии — механизм истории действий
затрагивает архитектуру пересчёта графа и не делается второпях.

## 🐛 Патчи 1.6.1–1.6.3 (после завершения плана 1.6.0)

- **Осиротевшие виджеты на Доске.** Удаление ноды «Дашборд» не убирало
  её виджет — он оставался навсегда с последним посчитанным значением.
- **Тормоза при редактировании виджетов Доски.** При нескольких
  виджетах одно нажатие клавиши могло вызывать десятки лишних
  пересборок DOM всей страницы Доски — перерисовка теперь откладывается
  до конца пересчёта графа, максимум один раз.
- **Ввод во 2-й/3-й/4-й виджет на Доске сбоил.** Алгоритм сверки DOM
  Доски мог без необходимости физически переместить поле, в которое
  пользователь прямо сейчас печатает — сбивало курсор. Первый виджет
  бага не показывал, остальные — да.
- **Двойной скролл в диаграмме Ганта.** Та же CSS-ловушка, что раньше
  чинили в «Просмотре таблицы» (v1.5.0): неявный `overflow-x: auto`
  заводил вторую горизонтальную полосу прокрутки поверх внешней.
