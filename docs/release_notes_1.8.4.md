# NodeCalculate v1.8.4 — release notes

Диапазон: v1.8.0 → v1.8.4. Старт релиза «обновление интерфейса и
дашбордов» — drag&drop импорта и первый шаг стартап-конфигов.

## Drag&drop импорта файлов

- Перетащите `.xlsx` или `.json` прямо в рабочую область листа — на
  месте появится соответствующая нода импорта, уже загруженная файлом.
  Отдельно выбирать файл через диалог не нужно.
- Если перетащить файл прямо на уже существующую ноду импорта
  подходящего типа — файл заменится в ней, новая нода не создаётся.
- Несколько файлов сразу — раскладываются по вертикали, не перекрывают
  друг друга.
- Багфикс: связи между нодами не отрисовывались сразу после
  drag&drop-импорта (появлялись только после следующего взаимодействия
  с холстом, например перетаскивания ноды). Причина — не был передан
  список соединений в функцию отрисовки при этом конкретном сценарии.

## Стартап-конфиги (первый шаг)

- Окно настроек (⚙️ в шапке сайдбара) стало полноценными настройками
  приложения — с вкладками. Вкладка «Сайдбар» — то, что было раньше.
  Новая вкладка «Запуск».
- На вкладке «Запуск» — можно сохранить текущее рабочее пространство
  (все листы, ноды, связи) как стартовое: при следующем открытии
  приложения оно откроется автоматически вместо демо-примера с тремя
  нодами. Там же — сброс к демо-примеру по умолчанию.
- Пока хранится в папке программы, не в пользовательском профиле — при
  переустановке приложения потребуется сохранить заново. Перенос в
  пользовательскую директорию (переживёт переустановку) — в планах,
  сознательно отложен на следующий шаг.
