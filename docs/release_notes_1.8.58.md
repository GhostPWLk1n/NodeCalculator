# NodeCalculate v1.8.58 — release notes

Диапазон: v1.8.36 → v1.8.58.

**Скачать:** [NodeCalculate-1.8.58-portable.zip](https://drive.google.com/file/d/1hRdUfmW0l9dKxddBMeXZLYXZxwMdn3T2/view?usp=drive_link)

Главное в этом релизе — клавиатурная и мышиная навигация по Диаграмме
Ганта, мультивыделение строк для массового редактирования, и большая
работа над виджетами Досок: живой формат «Web», независимая высота и
прокрутка, режим редактирования, и — самое важное — устранено
раздражающее зависание интерфейса виджета Диаграммы Ганта при
редактировании данных. Плюс — окно приветствия при запуске.

## Диаграмма Ганта — навигация и мультивыделение

### Клавиатурная навигация
- **Enter** переходит на следующее редактируемое поле строки (Раздел →
  Вид работ → Раб.дни → Ответственный), а с последнего поля — на первое
  поле следующей строки.
- **Стрелки влево/вправо** уважают позицию курсора внутри текста —
  перескакивают на соседнее поле только когда курсор уже у края,
  иначе просто двигают курсор как обычно.
- **Стрелки вверх/вниз** переходят на то же поле в соседней строке.
- Работает одинаково и на Листе, и в виджете на Доске.

### Мультивыделение строк (Shift+ЛКМ)
- Shift+клик по строке добавляет или убирает её из выделения, не
  трогая остальные уже выделенные строки. Обычный клик сбрасывает
  выделение.
- Изменение любого поля (Раздел, Вид работ, Раб.дни, Ответственный) в
  одной выделенной строке распространяется на все остальные
  выделенные строки.
- То же самое работает и для графического редактирования: **перетаскивание**
  полосы сдвигает все выделенные задачи на одинаковое число дней
  (сохраняя расстояния между ними), **растягивание** задаёт всем
  одинаковую итоговую длительность.
- Выделенные строки подсвечены явным акцентным фоном.

### Вставка из Excel
- Вставка (Ctrl+V) многострочного текста в поле названия задачи
  автоматически создаёт по новой строке на каждую строку вставленного
  текста, в правильном порядке — колонку из Excel теперь можно
  вставить одним движением, без ручного добавления строк.

## Диаграмма Ганта — данные и экспорт в Excel

- Новые колонки **«Сум.раб.дн.»** и **«Сум.ч.ч.»** — истинная сумма
  реально отработанных дней/часов по каждой задаче отдельно (в отличие
  от существующих «Раб.дн.»/«Кал.дни», которые считают по диапазону
  начало-конец диапазона всего раздела).
- Устранено ограничение на глубину вложенности при передаче данных
  между узлом обработки таблиц Ганта и самой диаграммой, а также при
  соединении «диаграмма → диаграмма» — иерархия разделов/подразделов
  теперь сохраняется на любую глубину, а не сплющивается после второго
  уровня.

## Доски — формат листа «Web»

- Формат «Web» теперь живьём подстраивается под размер окна — раньше
  ширина захватывалась только при запуске, разворачивание окна на весь
  экран не приводило к перерасчёту.
- Убран искусственный потолок ширины (1600px), мешавший листу
  растягиваться на широких мониторах.

## Доски — виджеты

- **Календарь** — виджет на Доске теперь показывает ту же
  интерактивную сетку месяца, что и сам узел на Листе, а не текстовую
  сводку.
- **Импорт (Excel/JSON)** — у обоих узлов импорта появились полноценные
  виджеты: можно выбрать файл и импортировать данные прямо с Доски, не
  переключаясь на Лист. (Раньше виджет либо отсутствовал, либо просто
  показывал уже импортированные данные как таблицу.)
- **Экспорт в Excel** — виджет на Доске теперь показывает вторую кнопку
  «Экспорт как календарь Ганта», которая раньше была только в теле
  самого узла.
- **Режим редактирования Досок** — новая кнопка в панели инструментов.
  Без включённого режима виджеты нельзя случайно сдвинуть или изменить
  им размер — доступно только их содержимое. Рамка выделения активного
  виджета тоже появляется только в этом режиме.
- **Высота виджета Диаграммы Ганта** отделена от высоты самого узла на
  Листе — растягивание одного больше не влияет на другой. У виджета
  появилась собственная ручка для изменения высоты.
- Позиция прокрутки внутри виджета Диаграммы Ганта (по горизонтали и
  вертикали) больше не сбрасывается на 0,0 при каждом изменении
  данных.

## Стабильность: зависание виджета Диаграммы Ганта

Долгая охота за плавающим багом: изменение данных внутри виджета
Диаграммы Ганта на Доске (правка поля, перетаскивание, добавление
строки) иногда «замораживало» интерфейс виджета — переставали
проходить клики и ввод, пока не переключишься на Лист и обратно.

Причин оказалось несколько, наложенных друг на друга:
- Перерисовка Доски иногда срабатывала синхронно прямо во время
  обработки того же события ввода, которое её и вызывало — из-за чего
  браузер иногда «терял» состояние фокуса. Теперь перерисовка всегда
  откладывается на следующий такт.
- Активное перетаскивание мышью (полосы, ручки изменения размера)
  могло попасть под пересборку виджета «из-под себя», если в этот
  момент срабатывал пересчёт из другой части графа — обработчики
  перетаскивания оставались висеть на уже удалённом элементе.
- Собственная защита Доски «не трогать виджет, пока в нём фокус ввода»
  (нужна для простых текстовых полей) конфликтовала с клавиатурной
  навигацией Диаграммы Ганта, которая постоянно удерживает фокус
  внутри виджета — из-за этого виджет мог вообще никогда не обновиться
  свежими данными.

Все три причины устранены; исправление проверено на сценариях правки
текста, перетаскивания, растягивания и добавления строк.

## Окно приветствия

При первом запуске (и при каждом следующем, пока не отключено вручную)
показывается окно приветствия — баннер, текущая версия, лицензии и
короткие советы по интерфейсу (например, про Shift+ЛКМ в Диаграмме
Ганта или про настройку своего набора узлов в сайдбаре), с
возможностью пролистать несколько подсказок. Галочка «Не показывать
при следующем запуске» отключает автопоказ; вернуть окно можно из
настроек (вкладка «Запуск»).
