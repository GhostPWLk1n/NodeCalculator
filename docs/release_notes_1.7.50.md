# NodeCalculate v1.7.50 — release notes

Диапазон: v1.7.34 → v1.7.50. В основном — доводка диаграммы Ганта до
рабочего состояния: закрепление столбцов, честный пересчёт дат
относительно календаря, цвета, редактирование прямо на диаграмме и
обратный экспорт в Excel.

## Диаграмма Ганта

### Закрепление столбцов и скролл
- Левые столбцы (№ п/п, Вид работ, ч.ч., Раб.дн., Ответственный, Кал.
  дни) теперь по-настоящему закреплены при горизонтальной прокрутке —
  для строк задач, групп и «Итого» одинаково.
- Исправлено фоновое «просвечивание» графика сквозь закреплённые
  столбцы — фон растягивался не на всю высоту строки, теперь на всю.
- Позиция прокрутки (и по горизонтали, и по вертикали) больше не
  сбрасывается в начало при каждом пересчёте — раньше терялась при
  любом изменении задачи.

### Расчёт дат — теперь всегда верный
- Единственные входы для расчёта длительности — «Начало» и «Раб.дни».
  «Окончание» и «Факт.дни» — чисто отображаемые поля, в расчёте не
  участвуют.
- Диаграмма сама пересчитывает итоговую дату через собственный
  календарь (выходные/праздники), а не берёт готовую дату из
  источника — источник больше не может «перекрыть» внутренний расчёт.
- Багфикс: после ручного или графического изменения протяжённости
  задача переставала реагировать на дальнейшие изменения календаря
  (переставали «прибавляться» выходные). Приведено к тому же принципу,
  что уже работал у списков.
- «Обработка таблиц Ганта» больше не запрашивает отдельный календарь —
  вся календарная логика теперь только на стороне самой диаграммы.

### Новая колонка «Кал. дни»
- Плюс к «ч.ч.» и «Раб.дн.» — календарные дни, с той же логикой
  показа/скрытия и той же формулой для «Итого» и групп.

### Цвета
- Пользовательские цвета для Ответственных и для Групп — своя палитра
  (Material) + произвольный цвет. Список имён собирается автоматически
  из данных, цвет — всегда явный выбор.
- Полоса задачи красится по цвету Ответственного (в приоритете) или
  Группы; индикатор группы — тем же цветом с прозрачной заливкой.

### Редактирование прямо на диаграмме
- Клик по номеру строки (или по отдельной узкой колонке перед ним)
  фиксирует фокус на строке — до следующего клика.
- В фокусе редактируются «Вид работ» и «Ответственный» прямо на месте.
- Появляются кнопки добавления и удаления строки; удаление группы —
  с подтверждением, если в ней есть задачи.
- Все ручные правки переживают пересчёт и сохранение проекта.

### Панель настроек (инспектор)
- Разбита на два блока: «⚙️ Настройки» (логика расчёта, развёрнут по
  умолчанию) и «📊 Отображение» (визуал, свёрнут по умолчанию).

## Обратный экспорт: диаграмма → раскрашенный Excel

Узел «Экспорт в Excel» умеет выгружать диаграмму Ганта обратно в тот
же календарный вид, который «Обработка таблиц Ганта» умеет читать при
импорте:

- та же структура (год/месяц/неделя в шапке, точки начала/конца задач
  цветом),
- объединение ячеек по месяцам и годам,
- реальная ширина столбцов (не 1:1 к пикселям — Excel считает ширину в
  символьных единицах шрифта, коэффициент подобран по факту),
- границы ячеек,
- те же колонки (ч.ч./Раб.дн./Ответственный/Кал. дни), что и на самой
  диаграмме, с той же логикой показа.

Экспортированный файл проверен независимым парсером (openpyxl) —
значения, цвета, объединения и ширина совпадают с ожидаемыми.

## Импорт Excel/JSON

Багфикс: цвета ячеек импортированного Excel-файла (нужны для разбора
дат по цвету) не сохранялись в проекте — после загрузки сохранённого
проекта приходилось заново выбирать и импортировать файл. Теперь
сохраняются вместе с остальными данными импорта.

## Сайдбар

- Иконка сайдбара заменена на настройки: список нод с флажками
  показать/скрыть, готовые конфигурации («Все ноды», «Графики Ганта»)
  и пользовательские, экспорт/импорт конфигурации в JSON.

## Минимальная ширина нод

Импорт/экспорт Excel и JSON, Календарь, Обработка таблиц Ганта —
заданы минимальные ширины, соблюдаются и при ручном изменении размера.
