# NodeCalculate — визуальный калькулятор на нодах

NodeCalculate — настольное приложение для расчётов и работы с данными,
вдохновлённое редакторами узлов (Blender, Unreal Engine). Вместо формул в
ячейках вы собираете граф вычислений, соединяя блоки (ноды) мышью —
от простого сложения двух чисел до импорта Excel/JSON, многоуровневых
таблиц с фильтрами и агрегацией, иерархических структур с раскрываемым
деревом и презентационных Досок (дашбордов) для готового результата.

**Текущая версия: 1.8.69**

---

## 🚀 Быстрый старт

```bash
git clone https://github.com/GhostPWLk1n/NodeCalculator.git
cd NodeCalculator
npm install
npm start
```

## 🛠 Стек

- **Electron** — настольное приложение (Windows/macOS/Linux)
- **Vanilla JavaScript (ES-модули)** — без фреймворков, полный контроль над DOM
- **SVG** — плавные кривые Безье для линий соединений, с градиентом по
  длине линии (цвет источника → цвет получателя)
- **CSS-переменные** — тёмная и светлая темы, переключаются на лету

## ✨ Возможности

- **Граф вычислений** — перетаскивание нод, соединение сокетов мышью,
  автоматический пересчёт всего графа при любом изменении
- **Листы (вкладки)** — несколько независимых холстов в одном проекте,
  с мостами данных между листами (`Вход/Выход листа`)
- **Доски (дашборды)** — отдельный презентационный холст: превращает
  любую ноду с данными в готовый виджет (число, текст, чекбокс,
  таблица, диаграмма, изображение) — можно редактировать значения
  прямо на Доске, менять размер и раскладку виджетов
- **Таблицы** — импорт из Excel (.xlsx) и JSON, инъекция/изъятие строк,
  слияние и объединение столбцов, фильтрация (в том числе по
  подключённым спискам условий с логикой истина/ложь), поиск
  уникальных значений с агрегацией, оформление (формат/цвет/итоги)
  отдельно от структуры данных
- **Деревья** — сборка иерархических структур из таблиц/списков с
  автоматическим расчётом итогов по совпадающим полям на каждом
  уровне; раскрываемый просмотрщик показывает вложенность вплоть до
  отдельных строк исходных данных; импорт JSON произвольной
  вложенности (включая "двойное кодирование" — JSON, сериализованный
  внутри JSON-строки) напрямую в дерево
- **Списки** — ручной ввод коллекций "имя:значение" с выбором типа
  данных (число/текст/логическое), преобразование таблицы в список и
  обратно с редактированием "на лету" и сохранением ручных правок при
  пересчёте графа
- **Инструменты холста** — вертикальная панель у края сайдбара:
  обрезание связей протягиванием жеста мышью через провода, точка-
  прокси для аккуратной прокладки линий, рамка выделения для
  группового перемещения нод
- **Поиск нод** в сайдбаре по названию и категории
- **Тёмная и светлая темы**, переключатель в шапке
- **Сохранение проекта** в собственный формат `.ncp` (JSON) —
  сохраняет граф, соединения, листы, Доски и историю разбора Excel

## 📦 Библиотека нод

### 🧩 Служебные
| Нода | Описание |
|---|---|
| Точка | Промежуточная точка на линии соединения — для аккуратной прокладки провода, без собственной логики вычисления (beta) |

### 📊 Входные данные
| Нода | Описание |
|---|---|
| Число | Ввод числа, компактная нода |
| Список (Имя-Аргумент) | Ручной ввод коллекции пар "имя:значение" — число, текст или логическое |
| Строка | Ввод текста |
| Булево | Переключатель истина/ложь |
| Изображение | Загрузка локального файла изображения — для оформления Досок |

### ➕ Операции
| Нода | Описание |
|---|---|
| Сложение / Вычитание / Умножение / Деление | Арифметика с произвольным числом входов |
| Логическая операция | И / ИЛИ / искл. ИЛИ / НЕ над несколькими логическими входами |

### 🔧 Преобразование
| Нода | Описание |
|---|---|
| Умножение списка | LIST → LIST с масштабирующим коэффициентом |
| Проценты от суммы | Доля каждого элемента списка от общей суммы |
| Диаграмма Ганта | Временная шкала задач с зависимостями и рабочими днями |
| Преобразование списка | Таблица или список → редактируемый список (три режима: имена из столбца, автоимена + значения, пара имя:значение) |

### 🗂️ Таблицы
| Нода | Описание |
|---|---|
| Таблица | Сборка таблицы из пар LIST + подпись столбца |
| Диаграмма | Столбчатая/линейная/круговая визуализация табличных данных |
| Импорт из Excel | Чтение .xlsx с выбором листа и строки заголовков |
| Импорт JSON | Разбор произвольного JSON (включая двойное кодирование) в таблицу + иерархию для дерева |
| Инъекция / Изъятие из таблицы | Точечное добавление или удаление строк |
| Оформление таблицы | Формат/ширина/цвет/итоги по столбцу — отдельно от структуры данных |
| Объединение столбцов | Схлопывание нескольких столбцов в один |
| Слияние таблиц | LEFT JOIN двух таблиц по ключевым столбцам с агрегацией по каждому столбцу |
| Отсеять | Фильтрация строк по условию на каждый столбец — текстом или подключённым списком "имя:истина/ложь" |
| Найти уникальные | Группировка по столбцу с агрегацией или исключением остальных |
| Дерево | Сборка иерархии из таблиц/списков с расчётом итогов по совпадающим полям |

### 📊 Визуализация
| Нода | Описание |
|---|---|
| Просмотр диаграммы | Круговая/кольцевая диаграмма по списку |
| Просмотр списка | Табличный просмотр списка |
| Просмотр таблицы | Прокручиваемый просмотр таблицы с сортировкой и итогами |
| Просмотр дерева | Раскрываемая/сворачиваемая иерархия — включая отдельные строки таблиц-листьев |

### 📑 Между листами
| Нода | Описание |
|---|---|
| Выход листа / Вход листа | Мост данных между разными листами (вкладками) проекта |

### 📊 Доски
| Нода | Описание |
|---|---|
| Дашборд | Превращает подключённую ноду в виджет на Доске |
| Оформление дерева | Формат/цвет/итоги по полям дерева перед показом на Доске |

## ⌨️ Управление

- **Клик** по ноде — выбор (открывает панель настроек справа)
- **Перетаскивание** по холсту — перемещение ноды(нод)
- **Перетаскивание** от сокета к сокету — создание соединения
- **Правая кнопка мыши** — контекстное меню ноды или соединения
- **Delete** — удаление выбранной ноды (или всех, выделенных рамкой)
- **Escape** — снять выделение, закрыть панель, выключить активный инструмент холста
- **Ctrl + колесо мыши** — зум холста
- Панель инструментов холста (у левого края, рядом с сайдбаром) —
  обрезание связей, точка-прокси, рамка выделения

## 🗂 Структура проекта

```
src/js/
├── main.js                 точка входа: регистрирует типы нод, глобальные window.*-функции
├── core/
│   ├── nodeManager.js       создание/рендер/удаление/drag/resize/выделение нод
│   ├── connectionManager.js создание/разрыв соединений между сокетами
│   ├── renderer.js          отрисовка SVG-линий (градиент по длине), подсветка сокетов
│   ├── boardManager.js      Доски (дашборды): раскладка, редактирование виджетов
│   └── layoutManager.js     листы (вкладки), сохранение/загрузка .ncp-проекта
├── nodes/                   ~35 типов нод, каждый — отдельный класс-наследник BaseNode
└── utils/
    ├── constants.js          имена типов, цвета, дефолтные конфиги
    ├── dataTypes.js          ListData/TableData — единые форматы данных между нодами
    ├── helpers.js            форматирование, generateId, строгое приведение типов
    ├── socketFactory.js      единая точка создания DOM-элемента сокета
    └── tableWidgetRenderer.js общий рендерер табличного виджета для Досок
```

Разработчикам, добавляющим новые типы нод: следуйте контракту в
[`docs/NODE_API.md`](./docs/NODE_API.md) — тогда новая нода автоматически
получит перетаскивание, сворачивание, растягивание по ширине, участие в
соединениях, сохранение в `.ncp` и переживание переключения листов без
единой правки в ядре.
